# Major Gift Prospect Prediction

Team Members: Kael and Dimitri

## Problem Statement
Higher education advancement offices have large alumni populations but limited time for prospect research. This project will use machine learning to predict whether an alumnus is likely to make a fiscal-year gift of at least $1,000.

## Dataset
Source: https://www.kaggle.com/datasets/michaelpawlus/fundraising-data

Our cleaned working dataset contains 1,000 alumni records.

## Goal
The goal is to identify potential major-gift prospects for human review.
